🎮 How to Play Show
🧩 Objective Be the first to collect all cards of the same type and press SHOW. 🃏 Game Setup • N players → N unique items selected from topic • Each item has N copies → total N×N cards • Each player receives exactly N cards 🔄 Turn Flow • Active player sees a "Your Turn" badge and timer starts • If you received a card from previous player: tap any card in your hand to swap it out • If you are the first player: tap any card in your hand to pass it • You cannot pass the same card you just received • You have 15 seconds — or a random card auto-passes 🏆 Winning • Collect all N cards of the same type → Press SHOW • Others complete a color-memory puzzle — fastest correct answer = highest rank
